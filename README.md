# Shift-schedule
Shift schedule
四班三輪輪班表

查詢與切換

打開就顯示今天所在的那一個月
上排可選年／月／日，按「查詢」跳到那個月，並標出那天
「今天」一鍵回到本月、標出當天
左右箭頭可換上／下月；手機可在月曆上左右滑換月
年份範圍大約 2020–2040（之後年度同一套輪班規則也能查）

月曆內容

每個格子有國曆日期、農曆、節氣
同時標 A／B／C／D 四股的班別：早、中、晚、休
班別後面有第幾天，例如早班第三天顯示 早 3
今天、查詢到的那天會用框線標出來

股別顯示

選「全部」：四股上下各一列，用股別顏色分（A紅、B藍、C綠、D紫）
選單一股：只顯示那一股，字較大，用班別顏色分（早綠、中藍、晚紫）
休假一律灰色

點日期

點某一天會從底部滑出當日詳情：星期、農曆、四股班別與時段

班表規則（依附圖）

20 天一循環：早5 → 休2 → 晚5 → 休2 → 中5 → 休1
A／B／C／D 各錯開 5 天，每天剛好一股早、一股中、一股晚、一股休
時段對照：早 07:00–15:10、中 15:00–23:10、晚 23:00–07:10
